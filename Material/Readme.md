# Dokumentation zum Material-Ordner
## ModelRepositoriesSheet
* Die Datei enthält unseren ersten Entwurf für ein Metadatenschema zur Beschreibung von Modellen.
* Das eigentliche Schema findet sich in den ersten drei Spalten: 
    * Category unterscheidet Kerneinträge und weitere Einträge
    * Subcategory weist inhaltliche Kategorien zu
    * Element enthält die einzelnen Metadatenfelder
* Die nächste Spalte enthält einen Beispieleintrag nämlich die Beschreibung des Modells aus dem Paper Dubos2023. Die gelbe Markierung kann ignoriert werden.
* Die letzte Spalte enthält Vorschläge für Ontologien und Vokabularien, die möglicherweise genutzt werden könnten, um mögliche Einträge zu beschränken. Das spielt erst bei einem späteren Ticket eine Rolle.
* Dubos2023 ist [dieses Paper](https://www.sciencedirect.com/science/article/pii/S030438002200360X): Dubos, V., St-Hilaire, A., & Bergeron, N. E. (2023). Fuzzy logic modelling of anadromous Arctic char spawning habitat from Nunavik Inuit knowledge. Ecological Modelling, 477, 110262.
